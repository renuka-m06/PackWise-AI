# Machine Learning Research Notebooks

This directory is designated for exploratory data analysis (EDA), sensitivity analysis, and postharvest respiration curve modeling notebooks.

## Notebook Naming Convention

- `01_eda_produce_respiration.ipynb`
- `02_barrier_permeability_distributions.ipynb`
- `03_shelf_life_kinetics_validation.ipynb`
- `04_topsis_weight_sensitivity_experiments.ipynb`

## Policy

- Notebooks must be committed with outputs cleared unless specifically documenting baseline benchmark runs.
- Do not commit large binary datasets directly into Git; reference data files from `data/raw/` or `data/processed/`.
